# Data Visualization and Analytics with R Programming

![R Language](https://img.shields.io/badge/R_4.6.1-276DC3?style=for-the-badge&logo=r&logoColor=white&logoSize=auto&label=Language&color=4169E1)

> **Utilizing R Programming Language and Packages for performing Data Visualization in the Fields of Economics, and Banking & Finance**

This repository main objective is to implement R programming for performing data visualization and analytics processes. It informs audiences the development of Economics and Banking & Finance landscapes within Indonesian economy perspective. Moreover, all visualizations are devised by employing various R packages for data visualization, including ggplot2 and plotly (ggplotly() function in particular).
